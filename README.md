## <img src="https://raw.githubusercontent.com/rosgear/rg-be-references-properties/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Справочник «Свойства элементов интерфейса»

Справочник свойств элементов интерфейса компонентов Панели управления GePanel.

Справочник входит в состав Панели управления GePanel и cлужит расширением для [модуля «Справочники»](https://github.com/rosgear/rg-be-reference).

### Скриншот
<img src="https://github.com/rosgear/rg-be-references-properties/blob/main/assets/help/grid.png?raw=true">

### Установка

Для добавления справочника в ваш проект, вы можете просто выполнить команду ниже:

```
$ composer require rosgear/rg-be-references-properties
```

или добавить в файл composer.json вашего проекта:
```
"require": {
    "rosgear/rg-be-references-properties": "*"
}
```
или скачать архив на [странице справочника](https://rosgear.ru/component/rg-be-references-properties/) в каталоге приложений RosGear.

После добавления справочника в проект выполните его установку в редакцию веб‑приложения с помощью Панели управления GePanel.

## <img src="https://raw.githubusercontent.com/rosgear/rg-be-references-properties/refs/heads/main/assets/images/icon.svg" width="64px" height="64px" align="absmiddle"> Reference «Properties of interface elements»

Reference of properties of interface elements of GePanel Control Panel components.

The reference is part of the GePanel Control Panel and serves as an extension for the [«References» module](https://github.com/rosgear/rg-be-reference).

### Screenshot
<img src="https://github.com/rosgear/rg-be-references-properties/blob/main/assets/help/grid.png?raw=true">

### Installation

To add the reference to your project, you can simply run the command below:

```
$ composer require rosgear/rg-be-references-properties
```

or add to your project's composer.json file:
```
"require": {
    "rosgear/rg-be-references-properties": "*"
}
```
or download the archive from the [reference page](https://rosgear.ru/component/rg-be-references-properties/) in the RosGear application catalog.

After adding the reference to the project, install it into the web application edition using the GePanel Control Panel.
